================================================================================
  INPUT
================================================================================

1. MarketQueryInput (Pydantic Model)
────────────────────────────────────

  Field           Type              Required    Example
  ─────────────   ───────────────   ────────    ─────────────────────
  commodity       str               ✅ Yes      "Wheat"
  state           Optional[str]     ❌ No       "Gujarat"
  district        Optional[str]     ❌ No       "Ahmedabad"
  local_market    Optional[str]     ❌ No       "Ahmedabad"

  Notes:
  • commodity is stripped of whitespace and control characters.
  • state, district, local_market are optional but improve accuracy:
      - state    → scopes Backend API fetch to a region (faster, more relevant)
      - district → enables same-district transport tier (₹50 vs ₹150+)
      - local_market → triggers SELL_IN_OTHER_MANDI detection

  ⚠ The `trend` parameter from v1 has been REMOVED.
    Trend is now computed internally (historical OLS + LSTM forecast).


SAMPLE INPUT (via API):
───────────────────────

  GET /api/market-intelligence/recommendation
      ?commodity=Wheat
      &state=Gujarat
      &district=Ahmedabad
      &local_market=Ahmedabad


SAMPLE INPUT (internal call):
─────────────────────────────

  input_data = MarketQueryInput(
      commodity="Wheat",
      state="Gujarat",
      district="Ahmedabad",

  )

  result = await run_market_agent(input_data)


================================================================================
  INTERNAL DATA (PriceRecord DTO — fetched from Backend API)
================================================================================

  Fetched via:
    GET {BACKEND_BASE_URL}/api/v1/market/prices
        ?commodity=Wheat
        &state=Gujarat        ← optional, narrows results
        &limit=200

  Each row is validated and converted to a PriceRecord DTO:

  Field           Type              Example          Notes
  ─────────────   ───────────────   ─────────────    ──────────────────────────
  commodity       str               "Wheat"          Required
  market          str               "Surat"          Required
  state           Optional[str]     "Gujarat"
  district        Optional[str]     "Surat"
  min_price       Optional[float]   2100.0           Must be > 0 to be valid
  max_price       Optional[float]   2600.0           Must be ≥ min_price
  modal_price     Optional[float]   2450.0           Primary price used in logic
  arrival_date    Optional[str]     "2026-04-25"     ISO date string
  variety         Optional[str]     "Lokwan"
  grade           Optional[str]     "FAQ"

  Validation:
  • Prices are coerced from strings if needed.
  • Records with modal_price = null or ≤ 0 are excluded from all logic.
  • min_price / max_price are auto-corrected if swapped.
  • Backend response can be a JSON array OR {"data": [...]} — both handled.


================================================================================
  OUTPUT
================================================================================

1. MarketRecommendation (Pydantic Model)
────────────────────────────────────────

  Field               Type                  Example               Notes
  ─────────────────   ───────────────────   ──────────────────    ──────────────────────────────
  commodity           str                   "Wheat"
  best_market         str                   "Surat"
  best_price          float                 2450.0                Modal price at best market (₹/qtl)
  best_profit         float                 2300.0                best_price − transport_cost
  transport_cost      float                 150.0                 ₹ to reach best market          ← NEW
  recommended_action  str                   "SELL_IN_OTHER_MANDI" SELL_NOW / SELL_IN_OTHER_MANDI / HOLD
  top_markets         List[RankedMarket]    (see below)
  reason              str                   "Surat offers ₹..."   Includes forecast note
  confidence          float (0–1)           0.78
  trend               Optional[str]         "stable"              Historical OLS trend            ← NEW
  predicted_price     Optional[float]       2510.0                LSTM / WMA forecast (₹/qtl)    ← NEW
  predicted_trend     Optional[str]         "increasing"          Direction of forecast           ← NEW
  data_points_used    int                   87                    Records used in decision        ← NEW

2. RankedMarket (sub-model inside top_markets)
──────────────────────────────────────────────

  Field           Type              Example
  ─────────────   ───────────────   ─────────────
  rank            int               1
  market          str               "Surat"
  state           Optional[str]     "Gujarat"
  district        Optional[str]     "Surat"
  price           float             2450.0
  profit          float             2300.0        net after transport
  transport_cost  float             150.0         ₹ from farmer's location

3. Possible Actions (recommended_action)
────────────────────────────────────────

  Action                  When Triggered
  ──────────────────────  ─────────────────────────────────────────────────────────────────
  SELL_NOW                Predicted trend is "decreasing" (price will fall — exit now)
                          OR best market is local with no better alternative
  SELL_IN_OTHER_MANDI     Best market ≠ local market AND profit advantage ≥ ₹100
  HOLD                    historical OR predicted trend is "increasing" AND
                          neither is "decreasing" AND confidence ≥ 0.40

  Priority order (first match wins):
    1. SELL_NOW  if predicted_trend == "decreasing" AND confidence ≥ 0.30
    2. HOLD      if either trend increasing, none decreasing, confidence ≥ 0.40
    3. SELL_IN_OTHER_MANDI if profit advantage ≥ MIN_PROFIT_TO_TRAVEL (₹100)
    4. SELL_NOW  (default)


================================================================================
  TRANSPORT COST TIERS  (₹ per quintal — config-driven, env-overridable)
================================================================================

  Tier                Condition                               Cost
  ──────────────────  ──────────────────────────────────────  ──────
  Same market         record.market == local_market           ₹0
  Same district       record.district == local_district       ₹50
  Same state          record.state == local_state             ₹150
  Adjacent state      state in STATE_ADJACENCY[local_state]   ₹300
  Distant / unknown   no match                                ₹500

  All comparisons are case-insensitive.
  Adjacency map covers all major Indian states (see config.py → STATE_ADJACENCY).
  All tier values are overridable via environment variables.


================================================================================
  FORECASTING
================================================================================

  The agent generates a price forecast using a waterfall strategy:

  Priority  Method                    Condition
  ────────  ────────────────────────  ──────────────────────────────────────────
  1         LSTM model                Model loaded AND ≥ 30 price records available
  2         Weighted moving average   ≥ 3 price records (7-day window, linear weights)
  3         Last known price          Fallback — no trend direction assigned

  Output:
    predicted_price  → forecast ₹ value
    predicted_trend  → "increasing" | "decreasing" | "stable"
                       (based on % change vs current price, ±2% threshold)

  LSTM details:
    • Input shape:   (1, LSTM_SEQUENCE_LENGTH, 1)  — default window = 30
    • Model file:    AI_Backend/ml/models/mandi_price_lstm.h5
    • Scaler file:   AI_Backend/ml/models/price_scaler.pkl  (optional)
    • Fallback norm: per-window min-max if scaler not found


================================================================================
  CONFIDENCE SCORE FACTORS
================================================================================

  Factor              Weight   Measures
  ──────────────────  ───────  ─────────────────────────────────────────────────
  Data coverage       0 – 0.30  Number of unique markets in fetched data
  Price consistency   0 – 0.30  Coefficient of variation (low CV = consistent data)
  Decisiveness        0 – 0.25  Profit gap between #1 and #2 ranked market
  Signal agreement    0 – 0.15  Historical trend and LSTM forecast agree / disagree ← NEW

  Thresholds (informational):
    High    confidence ≥ 0.70  → Decision is well-supported
    Medium  confidence ≥ 0.45  → Moderate certainty
    Low     confidence < 0.25  → Limited data; treat with caution

  Signal agreement detail:
    Both trends agree     → +0.15
    Partial (one stable)  → +0.07
    No signals            → +0.05
    Directly conflicting  → +0.00  (penalised)


================================================================================
  HISTORICAL TREND
================================================================================

  Computed via OLS (ordinary least squares) linear regression on modal_price.
  Requires ≥ 5 valid price records.

  Slope is normalised by mean price so the threshold is scale-independent
  (works for ₹50 vegetables and ₹5000 grains alike).

    normalised_slope > +2%  →  "increasing"
    normalised_slope < -2%  →  "decreasing"
    otherwise               →  "stable"


================================================================================
  PIPELINE STEPS
================================================================================

  ┌──────────────────────────────────────────────────────────────────────────┐
  │  Step  1 │ Ensure LSTM model loaded (once per process, lazy init)        │
  │  Step  2 │ Fetch prices from Backend API (with retry + state filter)     │
  │  Step  3 │ Validate data sufficiency (≥ 1 record required)               │
  │  Step  4 │ calculate_trend()       → historical OLS trend                │
  │  Step  5 │ predict_price_trend()   → LSTM / WMA / fallback forecast      │
  │  Step  6 │ find_best_market()      → MAX(modal_price − transport_cost)   │
  │  Step  7 │ rank_markets()          → Top 3 by profit (deduplicated)      │
  │  Step  8 │ calculate_confidence()  → 4-factor score (0–1)                │
  │  Step  9 │ determine_action()      → SELL_NOW / OTHER / HOLD             │
  │  Step 10 │ generate_reason()       → Quantitative farmer-friendly text   │
  │  Step 11 │ Assemble MarketRecommendation and return                       │
  └──────────────────────────────────────────────────────────────────────────┘
