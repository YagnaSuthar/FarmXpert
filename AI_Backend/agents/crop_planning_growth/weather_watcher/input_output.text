# Agrometeorology - methods
# ET0              FAO-56 Penman-Monteith (computed by Open-Meteo)
# spray window     daylight, wind 3-15 km/h, Delta-T 2-8 C (Stull 2011 wet bulb),
#                  temp <= 30 C, no rain in the hour or the 4 h after (rainfastness)
# fungal risk      leaf-wetness hours (RH >= 90 % or rain) at 15-30 C: >= 6 moderate, >= 10 high
# late blight      Hutton criteria: 2 consecutive days, Tmin >= 10 C and >= 6 h RH >= 90 %
# heat safety      NOAA heat index: danger >= 39.4 C, extreme danger >= 51.7 C
# dry spell        >= 2 days with rain < 1 mm and rain chance < 40 %
# New alert types: late_blight_risk, fungal_disease_risk, heat_safety.
# With hourly data, fungal_disease_risk replaces the cruder high_humidity alert.


# Alert thresholds
# heatwave        Tmax >= 45 C (critical >= 47)          IMD absolute criterion
# heat_stress     Tmax 40-45 C                           no departure-from-normal data, so not called a heat wave
# frost           Tmin <= 2 C (critical <= 0)
# cold_wave       Tmin <= 4 C                            IMD plains
# heavy_rainfall  >= 64.5 mm high; >= 115.6 critical     IMD 24 h categories
# storm/high_wind >= 39 km/h high; >= 62 critical        Beaufort 6 / 8
# high_humidity   daily mean >= 85 %                     fungal disease risk
# A hazard predicted by either forecast model raises an alert; its message says
# "(one forecast model)" when only one does.
