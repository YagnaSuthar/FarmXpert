# How readings are judged
# Moisture   plant-available water for the soil type (FAO-56 field capacity / wilting
#            point); stress below (1 - p) with the crop's FAO-56 p; above field
#            capacity + 5 points = waterlogging risk. Rice: below field capacity = low.
# Salinity   crop Maas-Hoffman threshold and slope -> expected relative yield.
#            Unknown crop: USDA classes (above 2 dS/m elevated, above 4 saline).
# Nutrients  crop optimal ranges; legumes get Rhizobium for low N, not urea.
# Amendments saline soil -> leaching + drainage; gypsum only when sodic (pH >= 8.5)
#            or strongly alkaline (pH >= 8.8, confirm with ESP).
# Score      weighted closeness to the crop's optimum minus alert impacts;
#            independent of the season label.
