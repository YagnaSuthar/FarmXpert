================================================================================
PRIORITY SCORING REFERENCE TABLE
================================================================================

  Formula: priority_score = (U×0.40 + R×0.35 + I×0.25) × trust_multiplier

  Agent Trust Multipliers:
    irrigation_agent    → 1.0
    soil_health_agent   → 1.0
    pest_disease_agent  → 1.1  ← elevated (pest damage is rapid)
    weather_agent       → 1.2  ← ground truth
    crop_selector_agent → 0.9
    growth_stage_agent  → 1.0

  Priority Bands:
    score ≥ 8.0   → CRITICAL  (Execute immediately)
    score ≥ 6.0   → HIGH      (Execute today)
    score ≥ 4.0   → MEDIUM    (Execute in 2–3 days)
    score ≥ 2.0   → LOW       (Execute this week)
    score < 2.0   → DEFERRED  (Reschedule when conditions allow)

  Example calculations:
    urgency=9, risk=9, impact=9, agent=pest_disease_agent:
      raw = (9×0.40)+(9×0.35)+(9×0.25) = 3.6+3.15+2.25 = 9.0
      score = 9.0 × 1.1 = 9.9 → CRITICAL

    urgency=5, risk=4, impact=6, agent=irrigation_agent:
      raw = (5×0.40)+(4×0.35)+(6×0.25) = 2.0+1.4+1.5 = 4.9
      score = 4.9 × 1.0 = 4.9 → MEDIUM

    urgency=2, risk=1, impact=3, agent=soil_health_agent:
      raw = (2×0.40)+(1×0.35)+(3×0.25) = 0.8+0.35+0.75 = 1.9
      score = 1.9 × 1.0 = 1.9 → DEFERRED
